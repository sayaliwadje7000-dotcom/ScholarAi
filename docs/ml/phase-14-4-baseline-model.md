# Phase 14.4 — Baseline Machine-Learning Model

## Objective

Implement the first trainable machine-learning model for
ScholarAI's recommendation system.

## Models

### 1. Logistic Regression

Purpose:
Predict whether a user-resource pair is relevant.

Target labels:

- 0: Not relevant
- 1: Relevant

Configuration:

- Solver: LBFGS
- Regularization: L2
- Class weighting: Balanced
- Maximum iterations: 1000
- Random state: 42

### 2. Dummy Classifier

Strategy:

- Prior probability baseline

Purpose:

Establish a non-learning reference benchmark.

## Input

Numerical feature matrices generated by Phase 14.3.

## Output

- Predicted relevance label
- Class probabilities
- Relevance probability
- Feature coefficients
- Training metadata

## Validation

The model validates:

- Matrix dimensions
- Numerical feature values
- Binary labels
- Class availability
- Feature names
- Sample weights
- Prediction dimensions

## Reproducibility

The random state and model hyperparameters are configurable.

## Privacy

User IDs and resource IDs are not model features.

## Important Limitation

The model implementation does not yet retrieve training data
from PostgreSQL.

The training dataset must be assembled and split into
training and evaluation sets in subsequent phases.
